User feedback uses the same visitor context as `SupportProvider`. The hook fills
visitor and contact IDs, handles validation, and submits a topic, rating, and
optional comment.

Use the default `<Feedback />` widget when you want the fastest path. Use
`useFeedbackForm` when you want your own shadcn UI.

## Hook exports

`useFeedbackForm` is exported from `@cossistant/react/hooks` and
`@cossistant/react/feedback`. Next.js apps can use the matching
`@cossistant/next/hooks` and `@cossistant/next/feedback` exports.
